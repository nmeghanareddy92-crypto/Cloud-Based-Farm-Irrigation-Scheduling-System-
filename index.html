Cloud Architecture

About the Cloud System

Connecting physical IoT soil telemetry with serverless cloud algorithms.

System Purpose & Vision

Traditional irrigation relies on fixed timers, leading to massive water wastage during rains and crop stress during heatwaves. Our Cloud-Based Farm Irrigation Scheduling System solves this by streaming IoT sensor telemetry directly to cloud computing infrastructure.

  • Serverless ET0 Analytics: AWS Lambda computes real-time crop water requirements.
  • IoT Telemetry Hub: AWS IoT Core handles thousands of sensor payloads over TLS v1.3 MQTT.
  • NoSQL Database Storage: Amazon DynamoDB guarantees sub-10ms schedule lookup speeds.

Cloud Pipeline Flow

1. ESP32 Field Node: Measures Soil Moisture %, Temp & Solar Irradiance
2. AWS IoT Core: Ingests encrypted MQTT telemetry JSON messages
3. Serverless Lambda: Computes Penman-Monteith Water Deficit & Triggers Valve
4. DynamoDB & Web UI: Persists schedules and presents real-time dashboard
